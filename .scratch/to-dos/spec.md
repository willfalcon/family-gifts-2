# To-dos

Status: in progress

The home screen's To do section, built from the user's data instead of mock items. See **To-do**, **Notice** and **Secret Santa off** in GLOSSARY.md.

## Behaviour

- A To-do is worked out by the app. It stays until it's no longer true or the user dismisses it. There's no checkbox.
- Tapping one goes to where you do it.
- Dismissing lasts for that occurrence: a Christmas or birthday to-do can come back next year; an event to-do never comes back.
- Sorted soonest first; on the same date, host to-dos (Send the names, Set up Secret Santa) first. Show 4, then "Show all". Hidden when there are none.

## Window

An occasion is "coming up" 4 weeks before it. December events that aren't birthday events, and Christmas lists, get 8 weeks.

## The to-dos

1. **Make a list** - you're going to an upcoming event (not cancelled) and have no list for it, Secret Santa or not. Also for your birthday, if it's set and not private, and you have no birthday list.
2. **Add a few ideas** - your list for an upcoming event, Christmas, your birthday or another date has fewer than 3 items, and someone can see it (event lists always count; others need a share).
3. **Set up Secret Santa** - you host an upcoming event with no Secret Santa, not turned off, not a birthday event, with 3+ people invited or going. Dismissing it turns Secret Santa off for the event.
4. **Send the names** - you host a Reviewed draw that's Drawn, not sent. Replaces the "Names are drawn" notice.
5. **Get your Secret Santa gift** - you have a Match, haven't marked Gift ready, and the event is within 2 weeks.

## Secret Santa off

- A setting on the event; any host can change it.
- Turned off from the event edit screen or by swiping the Secret Santa row on the event page; turned back on from the edit screen.
- Only before names are drawn. Turning it off deletes any draft setup (with a confirm).

## Out of scope

Reply-to-invite to-dos, a profile to-do, Nudges, Occasions on events.
