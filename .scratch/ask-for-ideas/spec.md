# Ask for ideas

Status: in progress

The first part of messaging. You can ask someone for gift ideas when they haven't made a list, and the Ask lands in a Thread between you. See **Ask** and **Thread** in GLOSSARY.md.

## Where you can ask

- On an event attendee row that says "No list yet", for anyone who has replied (going or can't go). Not for Invitees, not for yourself, and not on a cancelled event.
- On a person screen, when they have no lists you can see.
- Only Connections can be asked.

## The sheet

- Their avatar and name at the top.
- The occasion. From the event page it's that event. From a person screen it's a picker that defaults to your next shared upcoming occasion, and also offers "No occasion".
- A message box, pre-filled and editable, e.g. "Hey Mom! Any gift ideas for the Christmas party?"
- Suggestion chips: "Any sizes?", "What are you into lately?", "Experiences count too". Tapping one adds it as a new sentence and hides it.
- "Dad asked 2 days ago" when someone else has an open Ask to them for the same occasion. Names only, never what they wrote.
- "You asked 3 days ago" when you already have an open Ask to them for it. Sending adds to that Ask instead of making a second one.
- Send.

## Asks

- One per asker, per person, per occasion.
- Closes when the asked person has a list for that occasion with at least one item. The Thread gets a line: "Mom made a list for the Christmas party".
- Closes quietly 7 days after the occasion's date.
- Closes right away when the event is cancelled. Comes back if a host restores it (as long as it wouldn't have closed for another reason).
- An Ask with no occasion has no date, so it closes only when the person has a "Just ideas" list (no occasion) with at least one item.

## Threads

- 1:1 for now, but built so a Thread can have more people later (public asks).
- One Thread per pair of people. Every Ask between them goes into it.
- Text messages, Ask cards (with their occasion) and the "made a list" line. No read receipts, editing, deleting, photos or muting.
- Unread is tracked per person.
- If the two stop being Connections, the Thread is read-only for both, with a line saying why.

## Home screen

- A Threads section. A Thread shows while it has unread messages, or while it holds an open Ask to you.
- Open Asks to you for the same occasion are grouped in one card: "Christmas party · Dad and Sis asked for ideas", each Thread listed underneath, then a "Make a list" button.
- The asker sees their Thread only while it has unread messages.
- "See all" goes to every Thread.
- The Home tab shows a badge for unread messages.

## Out of scope

Push notifications, anonymous Secret Santa asks, public asks to an event or group, asks when someone has "not enough ideas", email.
